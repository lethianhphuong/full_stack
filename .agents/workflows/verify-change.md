# Xác minh thay đổi

Dùng skill `material-verify` để kiểm tra change set hiện tại, chọn bước xác minh phù hợp, chạy validation khả dụng và báo riêng các trạng thái `Đã đạt`, `Không đạt`, `Chưa chạy`, `Không khả dụng`.

Đối chiếu kết quả kiểm thử với plan, checklist và acceptance criteria. Không báo ready chỉ dựa trên build pass.
