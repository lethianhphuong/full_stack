# Quy tắc frontend

Khi làm việc trong `FE_material/`, dùng `docs/engineering/frontend-conventions.md`. Đọc thêm `docs/engineering/api-contracts.md` khi frontend sử dụng hành vi backend đã thay đổi. Code feature mới tuân theo kiến trúc mục tiêu; không refactor page legacy nếu không có yêu cầu.

Với công việc tập trung vào thiết kế, polish, styling hoặc review UI/UX, dùng skill `material-ui-craft`. Phát hiện styling trùng lặp và code smell theo tư duy DRY, nhưng không tạo abstraction sớm hoặc refactor ngoài phạm vi.
