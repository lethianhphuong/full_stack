# Quy chuẩn frontend đã được chuyển

Quy chuẩn frontend chính thức được duy trì tại `../docs/engineering/frontend-conventions.md`.

Hướng dẫn cho agent frontend nằm trong `AGENTS.md`. API contract dùng chung và hướng dẫn xác minh nằm trong `../docs/engineering/`. File trỏ này được giữ lại để các tham chiếu cũ không bị hỏng.
